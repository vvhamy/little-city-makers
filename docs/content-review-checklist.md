# Content review checklist

Use this for every new or changed mission, building or interface string.

## Learning
- [ ] The objective matches the steps
- [ ] Little and Junior versions both exist and differ in difficulty
- [ ] The target sentence is natural, correct English
- [ ] Vocabulary is taught in context

## Language
- [ ] Wrong answers are never correct English shown as acceptable
- [ ] Vietnamese and Korean glosses explain and never replace the English
- [ ] Vietnamese and Korean text has been reviewed by a fluent speaker

## Culture
- [ ] Facts are checked
- [ ] Wording says "many families", not "everyone"
- [ ] No stereotypes
- [ ] Fiction is clearly fiction

## Values and safety
- [ ] Every choice shows a consequence and a way to try again, with no shaming
- [ ] Nothing is frightening
- [ ] Nothing asks for personal information

## Technical
- [ ] `npm run check` passes
- [ ] Played in both modes and all three languages
